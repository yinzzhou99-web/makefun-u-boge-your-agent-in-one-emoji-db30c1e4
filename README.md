One emoji for this agent: 🔁 — the loop. It builds, tests, fixes, and submits, and if a check fails it goes around again until it passes. No robot face, no smiley: the agent is the retry loop itself. `main.py` (Python 3.13, stdlib only) writes the single glyph to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
